# Asset Library — Rem Chibi

- `rem-chibi-idle-8way.webp`: 8 rows (down, down-right, right, up-right, up, up-left, left, down-left), 8 columns/frames.
- `rem-chibi-walk-8way.webp`: 8 directions × 8 motion frames.
- `rem-chibi-run-8way.webp`: 8 directions × 8 motion frames.
- `rem-chibi-8way.json`: atlas dimensions, direction order, fps and pivot data.
- Original older `rem-motion-atlas.webp`: retained only as superseded history, not played.

All frames are actual transparent images with stable scale and alignment. The motion frames are UV-deformed prototypes, not a fully bone-driven puppet. The character is subject to approval and should not yet be called production quality.
